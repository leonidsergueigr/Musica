Musica

An audio player for the terminal, written in C++20. Browse your folders, build a queue, play playlists. Un lecteur audio pour le terminal, écrit en C++20. Parcourez vos dossiers, composez une file d'attente, lisez vos playlists.

InstallInstaller GitHub

DemoDémo

Recorded with VHS: folder browsing, playback, next track, search, track info, help. Enregistré avec VHS : parcours des dossiers, lecture, morceau suivant, recherche, infos du morceau, aide.

FeaturesFonctionnalités

  • Folder browserNavigateur de dossiers Move through your folders and start a track with Enter. Parcourez vos dossiers et lancez un morceau avec Entrée.
  • QueueFile d'attente Tracks play from a queue. n jumps to the next one. Les morceaux se lisent depuis une file d'attente. n passe au suivant.
  • Playlists Playlists are stored in ~/.config/musica/. Les playlists sont stockées dans ~/.config/musica/.
  • SpectrumSpectre A real-time audio spectrum. Un spectre audio en temps réel.
  • Covers and tagsPochettes et tags Shows the cover and the metadata of the playing track. Affiche la pochette et les métadonnées du morceau en cours.
  • SearchRecherche Press / to filter the browser panel as you type. Appuyez sur / pour filtrer le panneau de navigation pendant la frappe.
  • MouseSouris Mouse support is on by default. --no-mouse turns it off. La souris est activée par défaut. --no-mouse la désactive.
  • French and EnglishFrançais et anglais The interface exists in both languages. Choose one with --lang. L'interface existe dans les deux langues. Choisissez avec --lang.

InstallationInstallation

Musica 0.1.0 is published as Linux packages (x86_64) on the GitHub release page. Pick your format. Musica 0.1.0 est publié sous forme de paquets Linux (x86_64) sur la page de release GitHub. Choisissez votre format.

.deb (Debian, Ubuntu and derivatives).deb (Debian, Ubuntu et dérivées)

bash
curl -LO https://github.com/leonidsergueigr/Musica/releases/download/v0.1.0/musica-0.1.0-Linux.deb
sudo apt install ./musica-0.1.0-Linux.deb
musica --version

.rpm (Fedora and other RPM-based distributions).rpm (Fedora et autres distributions RPM)

bash
curl -LO https://github.com/leonidsergueigr/Musica/releases/download/v0.1.0/musica-0.1.0-Linux.rpm
sudo dnf install ./musica-0.1.0-Linux.rpm
musica --version

.tar.gz (any x86_64 Linux).tar.gz (tout Linux x86_64)

bash
curl -LO https://github.com/leonidsergueigr/Musica/releases/download/v0.1.0/musica-0.1.0-linux-x86_64.tar.gz
tar -xzf musica-0.1.0-linux-x86_64.tar.gz

Run the musica binary from the extracted folder. Lancez le binaire musica du dossier extrait.

Check the downloadVérifier le téléchargement

The release includes a SHA256SUMS file. Run this in the folder that holds your download. La release contient un fichier SHA256SUMS. Lancez ceci dans le dossier du téléchargement.

bash
curl -LO https://github.com/leonidsergueigr/Musica/releases/download/v0.1.0/SHA256SUMS
sha256sum --ignore-missing -c SHA256SUMS

Configuration

Musica keeps its playlists and its state file in ~/.config/musica/. It follows XDG_CONFIG_HOME when set. Musica garde ses playlists et son fichier d'état dans ~/.config/musica/. Il suit XDG_CONFIG_HOME s'il est défini.

OptionOptionEffectEffet
--langSet the interface language (French or English)Choisir la langue de l'interface (français ou anglais)
--no-mouseTurn off mouse supportDésactiver la souris
--helpPrint the help and exitAfficher l'aide et quitter
